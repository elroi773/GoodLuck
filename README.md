# 🎓 수능 응원 페이지

수험생 여러분을 응원하는 따뜻한 웹페이지입니다.  
응원의 메시지부터 대학 카드, 랜덤 명언, 그리고 수험표 할인 정보까지!  
수능 준비에 조금이나마 힘이 되어드리기 위해 제작했습니다.

## 📌 주요 기능

| 기능 | 설명 |
|------|------|
| 📢 응원 재생 기능 | 클릭 시 수험생을 위한 응원 음성이 재생됩니다. |
| 🏫 SKY 대학 카드 | 서울대, 고려대, 연세대의 상징 이미지와 응원의 문구가 담긴 카드 제공 |
| 💬 랜덤 명언 뽑기 | 클릭할 때마다 수험생에게 힘이 되는 명언을 랜덤으로 보여줍니다. |
| 🎁 수험표 할인 품목 | 수험표로 받을 수 있는 다양한 할인 정보 목록 제공 |

## 🛠️ 기술 스택

- **Frontend**: HTML, CSS, JavaScript
- **배포**: 클라우드타입
